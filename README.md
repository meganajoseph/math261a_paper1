# Potential Risk of Lead Exposure May Indicate Poverty Levels

## Author: Megan Joseph

## Date of submission: 10/29/2025

### Folder Structure
The data folder contains the raw data used in the project. The paper folder contains the Quarto markdown version of the paper, the pdf version, and the references bibtex file.

### External resources
External resources were only consulted for R code, mainly for syntax. No LLMs were used.

### The Data
The data used for this project comes from the [Calenviroscreen 4.0 tool](https://oehha.ca.gov/media/downloads/calenviroscreen/document/calenviroscreen40resultsdatadictionaryf2021.zip). There is no license, but there are no special restrictions or limitations on using the data.
